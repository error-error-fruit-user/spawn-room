# spawn-room

> **AI notice:** this project is developed with the help of AI. Much of the code and documentation was written with [Claude](https://claude.ai) (Anthropic), working under my direction and review. Commits that Claude helped write carry a `Co-Authored-By: Claude` trailer, so you can see which ones in the history.

A template for making Call of Duty zombies style maps and map packs for GZDoom/UZDoom, built on the [Horde Hammer](https://github.com/error-error-fruit-user/horde-hammer) library. Press **Use this template** on GitHub, rename it, and start mapping.

**Status:** early. The template gets filled in once Horde Hammer is usable.
